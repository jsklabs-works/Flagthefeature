    Message types reference

    The message formats you'll meet along the payment chain. Australian card networks use AS 2805 (the local ISO 8583 standard) for terminals, eftpos and ATMs. Visa and Mastercard use their own ISO 8583 variants. Account-to-account rails (NPP, HVCS) use ISO 20022. BECS still uses fixed-width ABA files.
